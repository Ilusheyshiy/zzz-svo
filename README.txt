КАПРИЗНЫЙ БОГ (Fabric, Minecraft 26.2, Java 25)

Сборка: установи JDK 25, затем в папке проекта:  gradle wrapper   (один раз, Gradle 9.5+)
        ./gradlew build        -> build/libs/moody_god-1.0.0.jar
Кидай jar + Fabric API в mods у обоих игроков (мод нужен и на сервере/хосте, и на клиентах).

Команды для теста: /god  (вызвать Бога сейчас),  /god wrath  (сразу в гневе)
Первый визит — через 3 минуты, дальше каждые 5-9 минут. Таймер сверху экрана.

ОБНОВЛЕНИЕ 2: 138 правил в пуле (57 активны в мире), реплика на каждое нарушение, овцы везде,
невидимый Бог (небо желтеет — это HUD-оверлей), "Милость" в таймере, смена настроения посреди речи.

ОБНОВЛЕНИЕ 3: Сатана на 5-й визит и дальше каждые 4-5; сцена с Кларком на 4-й визит (один раз);
рука с неба на поверхности; органы/конечности/части мозга как наказания; 33 дара; диско; 15 характеров;
перебивание Бога в чате = смерть; Пикл Рик взрывает; сжечь дар = жопа.
